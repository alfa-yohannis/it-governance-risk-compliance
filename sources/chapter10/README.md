# Sumber Bab 10: Kelangsungan Bisnis

| Berkas | Kegunaan |
| --- | --- |
| templat-bia.csv | Lembar kosong dampak menurut waktu, target, kapasitas, ketergantungan |
| contoh-bia-medikara.csv | Enam layanan rumah sakit Bekasi dengan asumsi terisi |
| perbandingan-strategi.csv | Tiga opsi biaya dan kemampuan untuk farmasi dan pendaftaran |
| praktik-dss04.csv | Delapan praktik DSS04, bukti, pemilik, dan status contoh |
| rencana-uji-pemulihan.csv | Pembagian 144 uji per tahun dan contoh hasil 36 uji triwulan pertama |
| skenario-tabletop-ransomware.md | Informasi bertahap, peran, lembar catatan, dan contoh hasil |

Buka CSV sebagai UTF-8 dengan pemisah koma di aplikasi spreadsheet. Baris pertama
tiap CSV berisi komentar kegunaan; buang baris itu bila aplikasi tidak mengenalinya.
Di dalam sel, tanda titik koma memisahkan butir, dan sel berisi koma diberi tanda kutip.
Semua angka tambahan adalah skenario fiktif.

Duplikasi templat, pilih lima sampai tujuh layanan, lalu validasi dampak dengan
pemilik layanan. Periksa kecocokan kapasitas dengan jumlah kunjungan keseluruhan.
Periksa RTO sebelum MTPD, kapasitas minimum, dan RPO yang didukung bukti. Jalankan
tabletop tanpa menyentuh sistem nyata. Uji pemulihan hanya pada sistem sendiri atau
yang berizin tertulis, memakai data sintetis. Luaran masuk C3. Target klinis pada
contoh bukan standar pelayanan dan harus divalidasi oleh pihak yang berwenang pada
organisasi nyata.
