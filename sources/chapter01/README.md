# Sumber Bab 01: Orientasi Mata Kuliah dan Dasar-Dasar GRC

| Berkas | Kegunaan |
| --- | --- |
| `templat-profil-organisasi.md` | Templat profil satu halaman, empat pemicu kasus, status informasi, peran tim, dan daftar periksa C1. |
| `peta-pemangku-kepentingan.csv` | Peta contoh delapan pemangku kepentingan untuk pemicu P-01, dengan peran keputusan, pengaruh, dampak, dan pelibatan. Sama dengan gambar peta pada Bab 01. |
| `panduan-izin-dan-anonimisasi.md` | Panduan izin, pengolahan bukti agregat, dan pemeriksaan sebelum berbagi. |
| `register-grc-awal.csv` | Register awal untuk pendalaman teknis: pemicu, risiko, kontrol, dan bukti yang saling tertaut. |

## Cara memakai

1. Salin berkas ke folder kerja tim; simpan versi contoh untuk pembanding.
2. Baca panduan Markdown sebelum mengisi CSV. CSV memakai UTF-8 dan pemisah koma. Baris pertama adalah komentar kegunaan, baris kedua adalah nama kolom. Hapus baris komentar bila berkas diimpor ke aplikasi spreadsheet.
3. Pilih contoh fiktif Medikara atau ganti dengan informasi organisasi yang telah memberi izin.
4. Isi bagian bertanda `...` dan tambahkan baris sesuai kebutuhan. Tanda ini adalah ruang kerja mahasiswa, bukan data contoh.
5. Tulis sumber, tanggal, pemilik, serta alasan keputusan. Jangan mengubah dugaan menjadi fakta.
6. Tinjau silang oleh anggota lain sebelum artefak digabung ke C1.

Semua angka tambahan dalam contoh merupakan pengandaian untuk pembelajaran. Rincian insiden vendor (akun dukungan vendor, 8 malam, 1.240 rekam kunjungan) adalah data latihan yang sama dengan mata kuliah IT40613, bukan fakta dasar kasus. Berkas ini tidak memuat data pribadi pasien atau karyawan. Tim menyimpan bukti asli pada tempat yang diizinkan organisasi dan hanya mencatat rujukan serta data agregat pada capstone.

## Hasil dan penilaian

Profil organisasi, daftar pemicu, dan peta pemangku kepentingan menjadi bagian C1. Artefak ini dipakai kembali ketika menyusun hak keputusan pada Bab 2 dan kewajiban pada Bab 3.

Kejelasan konteks 25 persen; hubungan pemicu dengan tujuan 30 persen; kelengkapan pemangku kepentingan 25 persen; keterlacakan bukti dan konsistensi lintas mata kuliah 20 persen.

Tidak diperlukan pemrograman. CSV dapat dibuka dengan aplikasi spreadsheet atau editor teks. Pilih UTF-8 dan pemisah koma jika aplikasi tidak mengenali kolom secara otomatis. `register-grc-awal.csv` hanya diperlukan untuk pendalaman teknis opsional.
