# Sumber Bab 11: Tata Kelola AI

| Berkas | Kegunaan |
| --- | --- |
| inventaris-ai.csv | Inventaris kosong tujuan, data, dampak, dan pengawasan |
| contoh-inventaris-ai.csv | Enam kasus AI Medikara; seluruh detail merupakan skenario |
| templat-kebijakan-ai.md | Aturan, persetujuan, alternatif, hak henti, dan tinjauan |
| rencana-evaluasi-ai.md | Ukuran awal, kesalahan kritis, kriteria lulus, serta batas klaim |
| contoh-hasil-uji-ai.csv | Contoh laporan uji AI-01 per kelompok usia |
| daftar-cek-owasp-llm.csv | Lembar kerja Pendalaman: sepuluh butir OWASP untuk satu kasus LLM |

Buka CSV sebagai UTF-8 dengan pemisah koma. Baris pertama berisi komentar dan
dapat dibuang bila aplikasi tidak mengenalinya. Pilih paling sedikit empat
kasus, nilai dampak, lalu tulis keputusan bersyarat. Kategori EU merupakan
pembanding sampai cakupan, tujuan penggunaan, serta peran organisasi dibuktikan.
Verifikasi perubahan aturan melalui EUR-Lex dan JDIH sebelum menyatakan
kewajiban. Gunakan data sintetis. Data pasien atau karyawan nyata tidak boleh
dimasukkan ke layanan AI mana pun. Luaran masuk C3.
